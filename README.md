## ⚡ 1-Minute Quick Start

### 1. Create your project
Click **"Use this template"** on GitHub, or clone locally:
```bash
git clone https://github.com/ZenDevvv/model-agnostic-agent-template.git my-new-project
cd my-new-project
```

### 2. Run the One-Click Setup
* **Windows (PowerShell):**
  ```powershell
  .\.template\setup.ps1
  ```
* **macOS / Linux / WSL (Bash):**
  ```bash
  bash .template/setup.sh
  ```

This configures your Git repository, installs Graphify, sets up post-commit hooks, and installs the Motion design profile by default. The setup script also supports frontend, minimal, and custom design profiles.

### 3. Start Building!
Open your AI coding assistant (Antigravity, Cursor, Claude Code, or Codex) and start chatting:
> *"I want to build a modern personal portfolio with React and Framer Motion."*

## 📂 Clean Project Structure

All background template tools, deep-dive guides, and setup scripts are neatly organized in the `.template/` dot-folder so they **never** clutter your actual application code:

```text
my-project/
├── .agents/             # 🤖 (Hidden) Agent skills & rules
├── .cursor/             # 🤖 (Hidden) Cursor IDE rules
├── .template/           # 📦 (Hidden) Template machinery, guides & setup
│   ├── docs/            #     All 9 deep-dive guides (Graphify, Ponytail, Impeccable, etc.)
│   ├── setup.ps1        #     Windows setup script
│   ├── setup.sh         #     macOS/Linux setup script
│   └── README.md        #     Comprehensive template reference & benchmarks
├── AGENTS.md            # 🤖 Universal entrypoint for AI coding agents
├── CLAUDE.md            # 🤖 Claude Code directives
├── GEMINI.md            # 🤖 Gemini / Antigravity IDE directives
└── README.md            # ⭐ This file (replace with your project's README!)
```

> **💡 Note for your project:** Once you initialize your project, feel free to replace this root `README.md` with your own project documentation. The complete template reference will always remain preserved in [`.template/README.md`](.template/README.md).
